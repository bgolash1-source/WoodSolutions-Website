Door setup (left panel)

This is where you tell DoorCut the size of the doors. Pick how you want to type your numbers first — Fractions, Decimal, or Millimeters. Once you add the first part to the list, that choice is locked for the job so the math stays consistent. See Overview help for the full list of what locks vs what you can still change.

Panel profile and shop note

Panel profile — Raised, Flat, or Custom — tells the shop how the panel is machined. It is copied into the yellow Shop Notes header and each new row. You can change it mid-job; only new adds pick up the new choice.

Note — optional extra text (required when profile is Custom). Same idea: new rows only unless you Clear Grid and rebuild.

How many and how big

Number of Doors is how many doors you are building at this exact size. Overall width and height are the finished door sizes — the size the door ends up after it is built, not the rough cut.

Add Door To Cutlist

This button builds all the frame and panel parts for the door style you picked in the sidebar and drops them in the grid. Open the door style from the sidebar first to set your stile and rail widths — otherwise it uses what is already there.
